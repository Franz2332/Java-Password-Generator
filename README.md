# Java Password Generator

A Random Password generator using Java

## Features
- Generates a random passwords which includes:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
  - User chooses password length

## Programs Used
- Java
- Eclipse IDE
- Git
- GitHub
